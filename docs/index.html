TIDAL-TUI

TIDAL-TUI is a keyboard-driven terminal client for TIDAL on Linux. It is designed to let a user sign in with TIDAL, browse the catalog, search tracks, albums, artists, and playlists, manage a playback queue, and control playback from a terminal interface.

Status

This project is under active development. Current implementation targets a native terminal interface with a Rust-based TUI, TIDAL API integration, and libmpv-backed playback.
