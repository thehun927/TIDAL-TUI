Privacy Policy for TIDAL-TUI

Effective date: June 7, 2026

TIDAL-TUI is a terminal user interface for TIDAL. This application is intended to let a user sign in to their own TIDAL account and access TIDAL features from a terminal environment.

Information Collected

TIDAL-TUI does not operate a backend service and does not intentionally collect or store personal data on a remote server.

The application may store the following information locally on the user's machine:

  • OAuth access tokens and refresh tokens issued by TIDAL
  • Local application configuration
  • Local playback queue and user interface state
  • Optional local cache data used to improve performance

How Data Is Used

The data stored locally is used only to:

  • authenticate the user with TIDAL
  • access the TIDAL API on behalf of the user
  • enable playback, search, library access, and related application features
  • preserve user settings and improve local application usability

Data Sharing

TIDAL-TUI does not sell, rent, or share user data with third parties. User data is only transmitted to TIDAL as required for authentication and API requests initiated by the user.

Data Retention

OAuth tokens and configuration data remain on the user's device until removed by the user or deleted by uninstalling the application or deleting the local configuration files.

Security

TIDAL-TUI stores authentication tokens locally on the user's device and limits file permissions where supported by the operating system. However, no software can guarantee absolute security.

Third-Party Services

TIDAL-TUI relies on TIDAL services and APIs. Use of TIDAL through this application is also subject to TIDAL's own terms, privacy policy, and platform rules.

User Control

Users can revoke access by:

  • deleting the locally stored token and configuration files
  • revoking the application's access through their TIDAL account or developer controls, if available

Contact

For questions about this privacy policy or this application, contact the project maintainer through the GitHub repository: github.com/thehun927/TIDAL-TUI

Changes

This privacy policy may be updated as the application evolves. Updated versions will be published at the same URL.
